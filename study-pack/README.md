## How to listen on a flight

1. Start with **Episode 00**. It is the map of the whole exam.
2. Then go in episode order. The series is built so later stochastic episodes reuse the point-estimate language from earlier ones.
3. When a host says “open the formula card,” that is [formulas.md](formulas.md). Screenshot that file before you lose wifi.
4. After you land, download the official PDFs from [sources.md](sources.md) and work one triangle by hand per paper.

If you later want NotebookLM-quality voices, paste each file in `podcasts/` into a NotebookLM notebook as a source and generate an Audio Overview. The scripts are already written as a two-host conversation.
