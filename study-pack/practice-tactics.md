# Practice tactics (October 2026)

Official practice items (not reproduced here): [Exam 7 page](https://www.casact.org/exam/exam-7-advanced-estimation-claims-liabilities), revised July 2026 (Item 3 revised July 14, 2026). Also: past exams, pass marks, examiners’ reports, Pearson sample item types.

## What the 4.5-hour appointment actually is

- Tutorial + confidentiality + survey eat clock around the edges.
- 4 hours 15 minutes of items.
- One optional 15-minute break.
- Spreadsheet items are **not** full Excel. Know what Pearson disables before you sit.

## Item types and how Exam 7 uses them

| Type | Typical Exam 7 use |
|---|---|
| Multiple choice | Which assumption failed; which method is Benktander; which model is CSR vs CAY |
| Multiple selection | “Select all diagnostics that apply”; easy to over-click |
| Point and click | Click the residual plot / triangle cell that shows a CY effect |
| Fill in the blank | A number: \(Z\), IBNR, \(dP\), a percentile if they gave the distribution |
| Matching | Method ↔ assumption; paper ↔ task |
| Constructed response | The points live here. Write the formula, the number, and **one sentence of why** |
| Spreadsheet | Tiny triangle → factors, Mack \(\sigma^2\), Clark increment, retro \(dP\), layer \(S\) |

## Standalone vs case

A **case** is a common triangle / treaty / retro book that several items share. If item 1 asks you to pick LDFs, item 3 will use *your* LDFs or the case’s selected ones. Read the case stem once, write the selected pattern on the scratch sheet, and do not re-litigate it on every item unless they ask you to.

## Cognitive-level translation

- **Remember (rare):** define quota share; write Weibull \(G(t)\).
- **Understand/Apply:** compute Benktander; compute Mack \(\hat f,\hat\sigma^2\); compute \(dP\).
- **Analyze/Evaluate:** Venter test failed — which method and why; Mack SE vs risk margin; ceded CL vs push-through.
- **Create (rare):** design a credibility mix or a Verrall \(\tau\) story and defend it.

Most of your points are in the middle two. A correct number with no method named often loses the analysis points.

## What graders have historically wanted (from public examiners’ reports, in spirit)

- Name the method before the arithmetic.
- State the assumption you are using when the data do not uniquely determine a pick.
- If a formula needs a distribution they did not give (Mack → 90th percentile), say so and pick one explicitly.
- Units and basis: paid vs incurred, limited vs ground-up, loss vs loss+ALAE, subject vs excess, AY vs treaty year.
- Do not spend ten minutes proving Hürlimann. The outline says you are not responsible for the proofs.

## A 60-second checklist before you submit a constructed response

1. Did I answer the thing they asked (IBNR vs ultimate vs premium asset vs margin)?
2. Is the basis consistent (the A4/A16 killer)?
3. If I mixed methods, is the weight between 0 and 1 and named (Benktander \(Z=p\), Brosius \(Z=\mathrm{VHM}/(\mathrm{VHM}+\mathrm{EVPV})\), Verrall \(\tau\))?
4. If I reported a percentile, did I name the distribution?
5. If I reported a risk margin, did I mention systemic risk or did I just recycle a Mack SE?

3. Only then open the solutions. Write one sentence: “I lost points because ___.”
